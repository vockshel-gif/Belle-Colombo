# Belle Colombo — Luxury Dining & Bar Web Application

A responsive, high-end web application crafted for **Belle Colombo**, showcasing luxury dining, artisan cocktail bar menus, multi-course tasting experiences, and dynamic event calendars.

---

## 🍽️ Features

- **Interactive Menu Hub**: Seamless navigation between À La Carte, Bar & Cocktails, Lunch & Dinner, and Multi-Course Tasting Menus.
- **Tasting Menus Experience**: Switch between the **5-Course Wine Pairing** and the **7-Course Grand Tasting** with pricing, curated pairings, and detailed dish notes.
- **Dynamic Event Calendar**: Filter by *All Events*, *Live Music*, *Cocktails*, and *Dining*, featuring date badges, status tags, and RSVP reservation CTAs.
- **Real-Time Operational Hours**: Displays exact service hours per menu section matching official offerings.
- **Mobile-First Luxury Aesthetic**: Designed with subtle gold accents, obsidian surfaces, haptic/click feedback, and smooth transitions.
- **Official Social Integration**: Direct links to WhatsApp reservations, Instagram, Facebook, and Google Maps.

## 🚀 Live Hosting & Deployment

The application is structured as a self-contained Single-Page Application (SPA) with `index.html` at the repository root.

### GitHub Pages (Recommended)
1. Navigate to **Repository Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your site will be live within seconds at:
   `https://vockshel-gif.github.io/Belle-Colombo/`

### Static Hosting (Vercel / Netlify / Cloudflare Pages)
- Simply import this repository; zero build configuration required (`index.html` at root).
